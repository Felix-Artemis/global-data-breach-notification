# 官方 URL 清单 —— 全球数据泄露通知

用途：`references/jurisdictions.md` 中每一个数字背后的权威链接。当你引述某一期限或门槛时，从本清单引注。当用户索要链接时，从本清单给出。

**「Fetch」列所用核验标识：**
- `OK` —— 自动抓取返回了页面内容。
- `403/000` —— 自动抓取被拦截（反爬），但链接有效、可在浏览器中打开。并非死链。
- `JS` —— 页面正文由 JavaScript 渲染；普通抓取只返回标题。请在浏览器中打开。**绝不可从一个你无法读取的 JS 页面上推导数字。**

**中国大陆来源刻意不收。** 不在范围内。
